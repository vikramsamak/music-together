# AGENTS.md

## Layout

Turborepo (npm workspaces, one git repo at root):
- `apps/api` — NestJS 11 backend, port 3001, socket.io gateway + Redis (Laragon, 127.0.0.1:6379, no auth)
- `apps/web` — Next.js 16 frontend, port 3000

Architecture decisions and the WS protocol: `docs/plans/README.md`. Implement the active phase from `docs/plans/` before adding features.

## Commands

- `npm run dev` / `npm run build` / `npm run lint` — turbo, both apps
- Single workspace: `npm run dev -w api` / `npm run dev -w web`
- API tests: `npm run test -w api`
- Smoke tests: start the api, then `node scripts/ws-smoke.mjs` (presence), `node scripts/chat-smoke.mjs` (chat), `node scripts/playback-smoke.mjs` (queue + sync), `node scripts/robustness-smoke.mjs` (frames/caps/TTL/lock); `node scripts/history-check.mjs write|read` needs an api restart between the two; `node scripts/restart-smoke.mjs` manages its own api on :3005
- Redis must be running or the api's Redis client logs errors; create-room/join will fail

## Gotchas

- Stable Next.js 16 has **no WebSocket API** — realtime lives in the NestJS gateway (`apps/api/src/rooms/room.gateway.ts`). Do not add `ws` to Next.
- `@nestjs/websockets` must stay on `^11` (v12 requires Nest 12 → peer conflict with this repo's Nest 11).
- Next 16: awaiting `params` in a page blocks prerender — wrap the awaited component in `<Suspense>` (see `apps/web/app/room/[id]/page.tsx`).
- The web eslint config includes `react-hooks/set-state-in-effect` — read localStorage via `useSyncExternalStore` (`apps/web/lib/name.ts`), not `useEffect`+`setState`.
- `apps/web/AGENTS.md` nextjs-agent-rules block is auto-regenerated by `next dev` — do not delete.
- Next docs ship in `node_modules/next/dist/docs/` (hoisted to the repo root after workspaces were added).
- Room state: Redis keys `room:{id}`, `room:{id}:queue`, `room:{id}:chat`. Presence is in-memory per API process (single instance).
- The web build runs on Port 3000 and the api on 3001 — socket.io CORS is configured for `WEB_ORIGIN` (`.env` in `apps/api`).
